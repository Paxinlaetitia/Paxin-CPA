# Dependências estáticas verificadas

O navegador não deve baixar código JavaScript executável de CDNs durante o uso
do Paxinbot. Dependências de terceiros são fixadas, armazenadas no repositório e
revisadas antes de uma atualização.

| Arquivo | Pacote de origem | Versão | SHA-256 |
| --- | --- | --- | --- |
| `assets/vendor/supabase-2.105.0.js` | `@supabase/supabase-js` | `2.105.0` | `24e8c00dc25da420ee741068b60bcdb5f62cb3598d8834058acf37ec6ee1a724` |

O arquivo foi extraído do pacote publicado no registro npm. Para atualizar,
fixe uma nova versão exata, confira o conteúdo, substitua o arquivo, atualize o
hash acima e execute a suíte completa antes de publicar.
